# Interview Prep Skills

A collection of reusable skills for interview preparation. Each skill lives in its own directory and contains a `SKILL.md` file with its instructions.

## System Design skill

The `system-design/` directory contains a distributed-systems and system-design interview coach. To use it, make the `system-design` skill available to your AI coding assistant by placing or linking the directory into that assistant's skills directory, then start a conversation about system design or distributed-systems interview preparation.

The skill can help you:

- **Learn a topic** in teaching mode, with interview-focused explanations and examples.
- **Practice an interview** in interview mode, with follow-up questions and structured feedback.

Tell the assistant which mode you want before beginning (or answer its mode clarification). You can also ask to continue or go again during practice.

For a quick start, ask: “Teach me CAP theorem for a senior system design interview” or “Run a mock interview on designing a URL shortener.”

## Mock AI Round skill

The [`mock-ai-round/`](mock-ai-round/) directory contains a HackerRank-style
AI-assisted coding exercise coach. Make the directory available in your AI
coding assistant's skills directory, then ask it to set up a round, optionally
with a topic or language—for example, “Set up a mock AI coding round in Python
about retrying a flaky API call.” It presents the requirements and starter-test
instructions, then collaborates on debugging, coverage, verification, and
interview follow-ups. See the [skill README](mock-ai-round/README.md) for more
examples and usage details.
